# il-009 · Code table: any character on a key

## Context
Owner, 2026-11-18: "need a browsable code table in inputlayer ₪ è ♪
whatever". The key picker only lists the characters that are already on
some layout, plus Music and Emoji, so ₪ (and most of Unicode) can't be
found there. Typing it with "Type text or emoji…" needs a keyboard that
has it already.

## Steps
1. Edit mode (quickequip ⇄), tap a key, pick a direction → **⌗ Code
   table…**.
2. Scroll the blocks; open "Currency symbols"; tap ₪.
3. Again → Code table, search `20AA`, then `sheqel`, then `grave`, then
   paste ♪.
4. In any picker (Add key…, the layout editor's quick, quickedit's add
   key), the **⌗ Code table** button opens the same table.
5. Long-press a character in the grid.

## Expected
- 1: every Unicode block with characters, in code order, each with its
  range and a preview of its first characters.
- 2: the block opens as a grid of large characters; tapping ₪ puts it on
  that direction of the key, and it types ₪.
- 3: `20AA` / `U+20AA` finds ₪ first; `sheqel` finds ₪ by its Unicode name
  (NEW SHEQEL SIGN); `grave` finds è among the letters with a grave; a
  pasted character finds itself. Blocks whose name matches show above the
  characters.
- 4: the same table, and the picked character lands where that picker
  puts keys.
- 5: a toast with the code point and name (U+20AA NEW SHEQEL SIGN).
- Characters the phone's fonts can't draw are left out (Android 6+), so
  no empty boxes.

## Shows in
`CodeTableTest` (blocks in order, ₪ in Currency symbols, hex / character /
name search, combining marks shown on ◌); on the device for the grid and
the font check.
