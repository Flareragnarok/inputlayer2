# il-009 · Code table: any character on a key

## Context
Owner, 2026-11-18: "need a browsable code table in inputlayer ₪ è ♪
whatever". Then (same day): "yea need like a grid table". The key picker only lists the characters that are already on
some layout, plus Music and Emoji, so ₪ (and most of Unicode) can't be
found there. Typing it with "Type text or emoji…" needs a keyboard that
has it already.

## Steps
1. Edit mode (quickequip ⇄), tap a key, pick a direction → **⌗ Code
   table…**.
2. Scroll the table, or **Blocks** → "Currency symbols"; tap ₪ (row
   20A8, column 2).
3. Again → Code table, search `20AA`, then `sheqel`, then `grave`, then
   paste ♪.
4. In any picker (Add key…, the layout editor's quick, quickedit's add
   key), the **⌗ Code table** button opens the same table.
5. Long-press a character in the table.

## Expected
- 1: one grid table like the Unicode charts: hex digits across the top
  (0–7 on a phone, 0–F on a wide screen), each row labelled with the code
  of its first cell, each block under its own title with its range, in
  code order. Empty codes are blank cells.
- 2: **Blocks** jumps to the block, the table stays open; tapping ₪ puts
  it on that direction of the key, and it types ₪.
- 3: `20AA` / `U+20AA` finds ₪ first; `sheqel` finds ₪ by its Unicode name
  (NEW SHEQEL SIGN); `grave` finds è among the letters with a grave; a
  pasted character finds itself. Blocks whose name matches show above the
  characters; tapping one jumps to it in the table.
- 4: the same table, and the picked character lands where that picker
  puts keys.
- 5: a toast with the code point and name (U+20AA NEW SHEQEL SIGN).
- Characters the phone's fonts can't draw are left out (Android 6+), so
  no empty boxes.

## Shows in
`CodeTableTest` (blocks in order, ₪ in Currency symbols, the grid's rows
and empty cells, hex / character / name search, combining marks shown on ◌); on the device for the grid and
the font check.
