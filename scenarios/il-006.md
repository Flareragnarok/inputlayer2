# il-006 · A full layout editor; saved layouts a key switches to

## Context
Owner, 2026-11-06: "integrate a full scale layout editor in settings where
we can add and remove and resize buttons liberally, save those layouts,
switch to via action key (backspace toggle or number toggle are technically
nothing else than switching between two layouts)".

Studio → Layout editor edits a whole keyboard: rows and keys, widths,
gaps, row heights, the nine names of every key (any key, text, app keys,
other layout keys, behaviour variants). Saved layouts are `layout` modules.
A key `layout:<name>` shows one as drawn (no bottom or number row added),
with the behaviours of a page (Studio → Keys: toggle, back after one key,
at the end of the word, after N s); "Add to my layouts" puts it in the
quick language's list instead.

## Steps
1. Use the keyboard once in any field; Studio → Layout editor: it opens
   with the keyboard as you use it.
2. Select a key, drag its right edge wider; select a row's free space, drag
   its bottom edge; + after; Names… → tap → Pick a key… → search.
3. Name it "Gaming", Save. Copy its key name; place `layout:Gaming` with
   edit mode → Replace with… (search "Your layouts").
4. Use the key; type; use ABC (or the key again).
5. Studio → Keys → layout:Gaming → "Back after one key typed on it"; use it.

## Expected
- 1-2: the canvas follows each change; Undo steps back; leaving with
  unsaved changes asks first.
- 3-4: the keyboard shows Gaming exactly as drawn; ABC or the key again
  goes back to the letters.
- 5: after one key on Gaming, the letters are back.

## Shows in
The keyboard; `LayoutDocTest` (editing, every slot and escaping through the
keyboard's own XML parser, JSON round trip, quick layout names).
