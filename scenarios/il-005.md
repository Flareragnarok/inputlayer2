# il-005 · Switching keys: a behaviour per use case, found with a key search

## Context
Owner, 2026-11-06: "studio keys like backspace toggle and repeat/layout
don't appear in settings for behaviour editing; integrate a keysearch for
behaviour modification and make multiple options for each of our
predefined keys per possible use case, e.g. layout/repeat: switch back to
repeat after calling once".

Switching keys: key repeat (studio_toggle_repeat; the quickequip's ↓
toggle_repeat), backspace direction (studio_backspace_toggle), backspace
split (split_backspace), edit mode (layout_mode), the pages switch_numeric,
il_symbols, il_symbols_more, switch_greekmath. Behaviours: toggle (as
before), back after one use (one key edit / one delete / one key typed on
the page), back at the end of the word, back after N seconds.

## Steps
1. Studio → Keys and behaviours → search "repeat" → studio_toggle_repeat →
   "Back after one key edit".
2. On the keyboard: quickequip ↓ (repeat off), hold a key, edit it, close
   the editor; hold a key again.
3. Place `il_symbols~once` with edit mode → Replace with… → search "~once";
   use it, type one symbol.

## Expected
- 1: the list shows ⇆ keys first with their current behaviour; the choice
  is saved and shown.
- 2: after the one edit, key repeat is on again (toast "Key repeat on");
  the second hold repeats instead of opening the editor.
- 3: the key shows ?123¹; after one symbol the letters are back. The plain
  ?123 key still toggles.

## Shows in
The keyboard's toasts and pages; `BehavioursTest` (once/word/timed per key,
manual way back, pages dropping each other's way back, variant names).
