# il-008 · Quick names: every action named by its function

## Context
Owner, 2026-11-06: "any action called is a quick"; "categorize them by
their function". Categories: quickfunction (the default, input and plain
functions, properties under them: quickfunction : backspace : direction),
quicktoggle (layouts: quicktoggle : layout : backspace / next / numbers…),
pageswitch (pages of one layout: symbols, symbols more, letters), quickopen
(app : …, layout editor, keys and behaviours, studio…), quickedit (the
right end's work: focus, resize, move, undo, menu), quickequip (equipping
keys: layout current = edit mode), quickbehaviour (key behaviour : long
press). The quicksbar's ends are called quickequip and quickedit.

Studio shows quick names; files keep legacy names ("show quick names,
upstream layouts can be converted in settings to quick names leaving a
replica of the legacy keys; quickfunction : type letter should be virtually
indistinguishable in performance to the legacy key").

## Steps
1. Studio → Keys and behaviours: scroll, search "quicktoggle", "copy",
   "?123".
2. Layout editor → Open → Convert a built-in layout to quick names… → QWERTY
   (US). Show XML; Add to my layouts; type with it.
3. Place `quickopen:layout editor` on a key; use it.

## Expected
- 1: every quick listed by category, quicktoggle first, each with its quick
  name; search finds quick names, legacy names and symbols.
- 2: two saved layouts, "QWERTY US" in quick names and "QWERTY US legacy";
  the XML shows quickfunction:type letter:q …; typing feels the same.
- 3: the layout editor opens.

## Shows in
`QuickNamesTest` (the owner's names, every special key and quicksbar action
both ways, same keys); `LayoutDocTest` (all 94 built-in layouts converted
load to the very same keys, locale-only keys kept).
