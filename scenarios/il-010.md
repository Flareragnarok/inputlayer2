# il-010 · Corruptions: your own piles of marks as a Verse look

## Context
Owner, 2026-11-18, showing "⩚̸̷⃫̨̣̖̩̰̤̙̥̱̜̭̦̳͙̪͖ ᛤ𝕥𝕠𝕚𝕝𝕖": "we got these
corruptions as well, we need a quicktable and verse". Asked what the table
should add to Verse, they chose "save a corruption as a Verse look": a set
of combining marks picked in the code table, saved as a look in Verse's
Marks nest and applied with Backspace ← like zalgo. Verse's zalgo only
piles random marks from U+0300–036F; ̸ ̷ ⃫ (overlays, marks for symbols)
can't be had. (The quicktable is a separate question, still open.)

## Steps
1. Studio → Edit strip tools → New corruption: name "slashed".
2. ⌗ Add marks…: the code table opens on the combining marks; tap ̸, ⃫,
   ̣ (search `solidus`, `dot below`); Done. Or paste marks in the field.
3. Watch the preview; ⌫ Last removes the last mark; Add.
4. On the keyboard: Verse → list → Marks → slashed; select a word;
   Backspace ←.
5. Verse → plain letters on the same word; Backspace ←.

## Expected
- 2: the table stays open while marks are added, each tap shows the
  preview; a character that isn't a combining mark is refused.
- 3: the preview shows "Corruption" with the marks on every letter; Add
  saves a `corruption` module (listed with the modules, exportable).
- 4: every character of the word gets the marks, in the order picked
  (ẉ̸⃫ọ̸⃫ṛ̸⃫ḍ̸⃫); slashed shows after zalgo in the Marks nest, written in
  its own look.
- 5: the plain word comes back, marks gone (even a one-mark corruption),
  while real accents (é, ñ) stay.

## Shows in
`CorruptionTest` (only marks accepted, built-in names refused, applied to
every letter, back to plain, recognized as the text's look, listed in the
Marks nest); on the device for the form and the table.
