# il-004 · A key brings the Remote Client up on a tab

## Context
Owner, 2026-11-05: "open client on a tab, brings it to top, possibly
opening the client from underneath other apps". Input Layer only opens the
client; it never sends anything to the desktop and never holds the SSH key.
The client accepts this only from apps signed with the owner's key
(Remote Client scenario rc-006).

## Steps
1. In any app, swipe ↑ on the suggestions key (comfort bar, second from
   left): the Remote Client comes up on Status.
2. Switch back, put `rc_roadmap` (or rc_commands, rc_doc, rc_setup,
   rc_status) on a key with layout mode, use it.
3. Uninstall the Remote Client and use the key again.

## Expected
- 1-2: the client's window comes to the front on that tab; if it was
  already open it is the same window, as it was.
- 3: a short message "Remote Client is not installed", nothing else.

## Shows in
The Remote Client's device log (`opened`, tab, from=inputlayer);
Input Layer's toast in step 3.

## Status
open
